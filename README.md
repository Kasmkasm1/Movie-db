# 🎬 Film & Dizi Arama Uygulaması (Movie & TV Show Search App)

TMDb (The Movie Database) API'si kullanılarak geliştirilmiş, modern ve responsive bir film/dizi arama web uygulaması. 

Kullanıcıların popüler filmleri keşfetmesini, arama yapmasını ve film detaylarına (puanlar, afişler vb.) anında ulaşmasını sağlayan şık bir ön yüz (front-end) projesidir.

---

## ✨ Özellikler

- 🔍 **Dinamik Film Arama:** TMDb API üzerinden anlık film ve dizi arama.
- 📱 **Tam Responsive Tasarım:** Mobil, tablet ve masaüstü cihazlarla uyumlu arayüz.
- 🍔 **Mobil Menü:** Hamburger menü entegrasyonu ile kolay navigasyon.
- 🎨 **Modern Arayüz (UI/UX):** Modern CSS teknikleri ve `backdrop-filter` (blur) efektleri ile şık görünüm.
- ⭐️ **Film Detayları & Puanlar:** Film afişleri, puan bilgileri ve açıklamalarının ızgara (grid) düzeninde listelenmesi.

---

## 🛠️ Kullanılan Teknolojiler

- **HTML5:** Sayfa yapısı ve semantik etiketler.
- **CSS3:** Özel stiller, responsive tasarım, Flexbox & CSS Grid, blurred backdrop efektleri.
- **JavaScript (ES6+):** TMDb API entegrasyonu, DOM manipülasyonu ve dinamik veri işleme.
- **TMDb API:** Film ve dizi verilerini çekmek için kullanılan RESTful API.

## 🚀 Kurulum ve Çalıştırma

Projeyi yerel bilgisayarınızda çalıştırmak için aşağıdaki adımları takip edebilirsiniz:

1. **Repoyu klonlayın:**
   ```bash
   git clone https://github.com/kullanici-adiniz/film-arama-uygulamasi.git
   ```

2. **Proje dizinine gidin:**
   ```bash
   cd film-arama-uygulamasi
   ```

3. **API Anahtarı Edinin:**
   - [TMDb (The Movie Database)](https://www.themoviedb.org/) sitesinden ücretsiz bir hesap oluşturun ve API Anahtarınızı (API Key) alın.

4. **API Anahtarını Ekleyin:**
   - `script.js` (veya ilgili JavaScript dosyanız) içerisindeki API key değişkenine kendi anahtarınızı tanımlayın:
     ```javascript
     const API_KEY = 'SİZİN_TMDB_API_KEYINIZ';
     ```

5. **Uygulamayı Başlatın:**
   - `index.html` dosyasını tarayıcınızda açarak projeyi hemen kullanmaya başlayabilirsiniz.
